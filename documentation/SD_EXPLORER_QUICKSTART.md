# 🎯 SD Card Explorer - Quick Start Guide

## What's New?

Your SC64 deployer GUI now has a **professional file explorer** for managing SD card files! This replaces the old command-button interface with a familiar drag-and-drop experience.

## 🚀 Quick Start

1. **Select your deployer**: `File` → `Select sc64deployer`
2. **Click the "SD Card Explorer" tab**
3. **Start managing your files!**

## 📁 Main Operations

| Operation | How To |
|-----------|--------|
| **Browse files** | Double-click folders to navigate |
| **Upload files** | Drag & drop from your PC or click "Upload File" |
| **Download files** | Select file → Click "Download" |
| **Rename files** | Select file → Click "Rename" |
| **Delete files** | Select file → Click "Delete" (⚠️ no undo!) |
| **Go back** | Double-click ".." or use "Navigate to path" |

## 💡 Tips & Tricks

- **Batch upload**: Drag multiple files at once
- **Navigate anywhere**: Type path in "Navigate to path" field (e.g., `/roms`, `/saves`)
- **Context menu**: Right-click files for quick options
- **Stay responsive**: Operations run in background, UI never freezes
- **Auto-refresh**: File tree updates automatically after each operation

## ⚠️ Important Notes

- ❌ **Deleted files cannot be recovered** - Be careful with the Delete button!
- 📍 Root directory is `/`
- 🔄 Auto-refresh happens after every operation
- 🖥️ Original command interface still available in "Commands" tab for advanced users

## 🎮 Still Using the Old Interface?

The original command-based interface is still available! Both tabs work together:
- **Commands tab**: For advanced operations and scripting
- **SD Card Explorer tab**: For everyday file management

Choose whichever works best for your workflow!

## 📋 File Tree Display

The file tree shows:
- 📁 **Folders** with folder icon
- 📄 **Files** with file icon
- 📊 **File types** and sizes (when available)

Navigate by:
- **Double-click** folder to open it
- **Double-click ".."** to go up one level
- **Type path** in navigation field and press Enter

## 🆘 Something Not Working?

1. Check that deployer is selected (shows path at bottom)
2. Verify SC64 device is connected
3. Look at status bar for error messages
4. Try using the "Refresh" button
5. Check console output for technical details
